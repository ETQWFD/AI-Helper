# AI帮助器 (AI Helper) v0.1

> 开发者: ETC (ET协会) | License: MIT

一款基于无障碍服务的 Android AI 助手应用。AI 可以读取屏幕内容，通过点击、滑动、输入等操作帮助用户完成任务，包括辅助游戏操作。

## 功能特性

- **AI 聊天**: 配置自定义 AI（地址/Key/模型）或使用申请的预设 AI
- **无障碍操作**: AI 可读取屏幕并执行点击、滑动、文字输入、返回、主页等操作
- **账号系统**: 邮箱申请账号，登录后免配置 AI，支持专属头像
- **实时同步**: 账号状态与 GitHub 仓库实时同步，支持封禁管理
- **自动更新**: 检测 GitHub Release 新版本，应用内下载安装
- **环境检测**: 仅支持真机及授权虚拟机（UU虚拟机、光速虚拟机）
- **暗黑模式**: 精致暗色 UI 设计

## 使用方法

1. 首次运行会显示账号申请说明
2. 在主界面点击「获取无障碍模式」，在系统设置中开启无障碍服务（每次启动需重新确认）
3. 在「设置」中配置 AI：
   - 自定义 AI：输入完整的 API 地址、Key 和模型名称
   - 申请的 AI：登录账号后使用开发者预配置的 AI
4. 点击「开始」，确认无障碍和 AI 配置后进入聊天界面
5. 输入需求，AI 会分析屏幕并执行操作

```bash

./gradlew assembleRelease
```

APK 输出路径: `app/build/outputs/apk/release/`
