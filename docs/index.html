运行内存最低 2GB，建议 3GB 以上
存储空间至少 50MB 可用空间
网络AI 对话需要网络连接

使用步骤

安装应用

下载 APK 文件后点击安装，如提示未知来源，请在系统设置中允许安装。

首次启动

首次运行显示账号申请说明，可点击返回跳过，使用自定义 AI 模式。

开启无障碍

在主界面点击「获取无障碍模式」，跳转系统设置开启 AI帮助器 的无障碍服务。每次启动需重新确认。

配置 AI

进入「设置」，选择自定义 AI（输入 API 地址、Key、模型名称）或登录账号后使用申请的预设 AI。

开始使用

返回主界面点击「开始」，进入聊天界面，输入需求，AI 会分析屏幕并自动执行操作。

申请账号（可选）

发送邮件至 etqe1234@outlook.com，包含真实名称、用户名、联系方式和密码，审核通过后可免配置 AI。
