📖 使用方法

  1. 下载并安装 AI帮助器 APK
  2. 首次运行查看账号申请说明（可跳过，使用自定义AI）
  3. 在主界面点击「获取无障碍模式」，在系统设置中开启无障碍服务
  4. 在「设置」中配置AI：自定义AI（输入地址/Key/模型）或登录后使用申请的AI
  5. 返回主界面点击「开始」，进入聊天界面
  6. 输入你的需求，AI会分析屏幕并自动执行操作
