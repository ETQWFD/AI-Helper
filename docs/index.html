AI帮助器

基于无障碍服务的安卓辅助工具。通过读取屏幕内容并执行点击、滑动、输入等操作，帮助用户完成设备上的各类任务。

功能说明

对话交互

支持自定义 API 配置或登录后使用预设配置，通过自然语言下达操作指令。

无障碍操作

可读取屏幕元素并执行点击、滑动、文字输入、返回、主页等操作。

游戏辅助

以正常操作水平辅助游戏运行，不修改数据，不使用非常规手段。

账号管理

邮箱申请账号，登录后免配置，支持头像和状态同步。

自动更新

检测 Release 新版本，应用内下载安装，支持国内镜像加速。

环境保护

仅在授权环境运行，不触碰用户个人文件和数据。

使用步骤

安装应用

下载 APK 后点击安装，提示未知来源时在系统设置中允许。

首次启动

首次运行显示使用说明和账号申请信息，可返回跳过。

开启无障碍

主界面点击「获取无障碍模式」，在系统设置中开启本应用的无障碍服务。

配置接口

进入设置，填写自定义 API 地址、密钥和模型名称；或登录账号使用预设配置。

开始运行

返回主界面点击「开始」，输入指令，工具将分析屏幕并执行对应操作。

申请账号

发送邮件至 etqe1234@outlook.com，附真实名称、用户名、联系方式和密码。
